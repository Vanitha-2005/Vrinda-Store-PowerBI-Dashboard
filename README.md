# Vrinda Store Power BI Dashboard

## 1. Project Overview
This project analyzes Vrinda Store sales data using Microsoft Power BI to understand sales performance, customer behavior, and business trends.

## 2. Project Objectives
- Analyze overall sales performance.
- Identify top-performing product categories.
- Understand customer purchasing patterns.
- Compare sales across different states.
- Analyze monthly sales trends.
- Track order status and sales channels.

## 3. Tools and Technologies
- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX
- Data Visualization

## 4. Data Preparation
- Checked the dataset for missing values.
- Removed duplicate records where required.
- Corrected data formats.
- Prepared data for analysis.
- Created relationships and measures where needed.

## 5. Key Performance Indicators (KPIs)
- Total Sales
- Total Orders
- Total Quantity
- Total Customers

## 6. Dashboard Features
- Interactive filters and slicers.
- Monthly sales analysis.
- Category-wise sales comparison.
- Gender-wise order analysis.
- State-wise sales analysis.
- Order status distribution.
- Channel-wise sales performance.
- Interactive charts and KPI cards.

## 7. Business Insights
- Identify high-performing product categories.
- Understand monthly sales patterns.
- Compare customer orders by gender.
- Find states contributing more to sales.
- Monitor order status distribution.
- Compare sales performance across channels.

## 8. Project Outcome
This dashboard helps users explore sales data, identify business trends, and make data-driven decisions.

## 9. Files Included
- Power BI dashboard file (.pbix)
- Raw dataset
- Cleaned dataset
- Dashboard screenshot

## 10. Conclusion
The Vrinda Store Power BI Dashboard provides an interactive view of sales performance and customer purchasing patterns. It helps summarize important business information in one place.
